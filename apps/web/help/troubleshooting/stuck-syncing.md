## First, tap the chip

The sync panel shows what is queued and when it last synced. Two normal cases:

- **Downloading company data** on a new device can take a minute on a slow connection. Let it finish.
- **Offline** with changes queued is fine. They send when signal returns.

## If it is stuck with signal

1. Check that other apps have internet.
2. Close ShotLog fully and open it again.
3. If the panel says **"Can't reach server"** for more than a few minutes while other sites load, the server may be down — check with Matthew. The probe that watches the server emails him when it fails.
4. As a last step, **Reset local data** in the sync panel. See [Reset local data](/help/troubleshooting/reset-local-data).
